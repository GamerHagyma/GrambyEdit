# Local symmetry tools

The Mirror inspector tab supports planar placement reflection and radial copies. Set a selected native Part or Connector as the anchor; its committed world frame supplies the local axes. Plane normal/axis offset and Euler rotation adjust the guide independently of the build. Top face uses the anchor mesh's upper Y bound; Center resets the offset and rotation. The radial sector count is 2–16 including the original. Guide size affects only drawing.

Apply copies the selected parts, optionally including attached descendants once, excluding the anchor. Originals remain. Automatic symmetry is opt-in and participates in explicit placement paths: Place (including drag/drop, paste and generated sub-builds), Connect picker, generators onto a host and surfaces onto a host. It does not repeat property changes, moving existing parts, duplication commands, incoming collaboration updates or undo/redo.

Settings are held in `state/symmetry.ts`, outside `Doc`, preferences, share codes, history and room messages. Guides and dry-run previews use separate viewport layers excluded from picking. A full workspace replacement or missing/invalid anchor clears the setup; ordinary selection changes do not. During collaboration only the ordinary resulting document edit is shared, using the user's existing ID lease. Viewers can configure local guides but cannot Apply or place parts.

Each operation clones native parts with fresh IDs and fresh UUIDs for all copied attachment points. Internal connections remap to copies; connections to parts outside the copied set are omitted. Copy roots attach to the symmetry anchor using actual ephemeral points, not editor-only root layout, so their positions survive share-code export. Radial copying is a rigid transform and preserves valid internal socket joints. Planar copying maps corresponding native sockets, recomputes point frames and replaces structural pose joints with point mounts where needed. It preserves an internal signal joint when a free mount can seat its body; otherwise it refuses the operation instead of silently breaking the wire. Replacing a structural joint with a point can change in-game mechanical behavior; check mechanical assemblies in game.

Every independently placed body is transformed. The operation verifies final computed body poses before committing; a failure rolls back original placement and all copies. Cyclic assemblies must be resolved first. Root-only parts without an available child mount cannot be copied onto the anchor.

The format stores rotations but has no mesh-scale field. Plane reflection therefore mirrors placement frames, using a local reflection correction to keep a proper rotation. Native asymmetric geometry retains its shape. DoorA/B and DoorC/D variants swap; Servo and Servo_Physics use a local Y correction with negated remembered Rotation. No claim is made that arbitrary chiral meshes are geometrically reflected or that physics are simulated.

Centered parts are skipped by default; disabling that option permits radial fan patterns about their center. Already-present identical type/property/body frames are reused rather than stacked. Operations allow at most 8,000 candidate additional parts and 32,000 total parts. Selection preview is omitted above 500 candidate copies, while Apply remains available. Automatic ghost instances are a lightweight placement preview; final placement uses the validated body-aware copy operation.

Checks cover arbitrary/offset planes, radial sectors, native socket mapping, export roundtrips, nested point mounts, fresh UUIDs, independent wire ends, conditional placement, local state, viewer permissions and atomic undo. Browser checks cover actual viewport placement and local guides alongside shared results.
